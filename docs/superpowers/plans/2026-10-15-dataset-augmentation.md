# 학습 데이터셋 증강

사용자의 추가 구현 요청에 따라 기존 데이터셋 페이지/생성 서비스에 통합한다. 원본 분할 후 학습에만 증강을 추가하고 검증 이미지는 그대로 보존한다. SAM 작업과 별개로 원본 주석을 수정하지 않는다.

## 구현

1. OpenCV/NumPy 증강 서비스: 좌우/상하 반전, 회전·크기·이동, 밝기·대비, 색상, 노이즈, 약한 blur. 영상은 선형 보간, 마스크는 최근접/0 경계. seed 기반 재현, 클래스 보존, 사라진 작은 객체 보고.
2. build_dataset(..., augmentation=None): 원본 먼저 split. train 원본마다 1~20개 추가 PNG/YOLO polygon. 기존 원본/데이터셋 불변, staging 실패 정리. 보고서에 원본 split, 생성 provenance/설정/변환/제외 객체 기록.
3. 기존 데이터셋 화면: 켜기/끄기, 생성 수, 세부 옵션, 원본/증강 마스크 미리보기, 생성 수 보고. UI는 기존 작업 스레드를 재사용한다.
4. RED→GREEN 테스트: 영상과 마스크 정합, 원본 보존, 분할 누수 방지, 재현성과 설정 검증, UI를 통한 실제 데이터셋 생성. 전체 테스트·스크린샷·독립 검토.

## 검토 초점

- 같은 원본의 증강이 train/val 양쪽으로 섞이지 않는다.
- 기하 변환된 마스크에서 클래스/정규화 좌표/객체 제거 처리가 맞는다.
- 증강본 파일 충돌/부분 생성 실패가 원본과 이전 snapshot에 영향을 주지 않는다.
- 미리보기는 사용자 원본/주석을 수정하지 않는다.

## 기록

- Ultralytics는 학습 중 online augmentation도 지원하지만, 이번 기능은 UI에서 확인 가능한 별도 학습 이미지 생성을 추가한다. 학습 기본 증강 설정은 바꾸지 않는다.
- 서비스/화면/미리보기/보고서 구현 완료. 원본 + 추가 장수 표시, 검증 원본 유지 및 기본 증강 꺼짐 확인.
- 독립 검토의 생성 중 reviewed 주석 변경 문제를 재현하고, 주석 리비전 비교 및 staging 정리 회귀 테스트로 RED→GREEN 수정.
- 전체 pytest 92개 통과, 실제 SAM2 GPU 어댑터 확인 및 1440×940 화면 캡처 확인. 원본 사용자 데이터는 검증용으로 변경하지 않았음.
- 실제 Qt 마우스 포함·제외 클릭 → SAM2 CUDA → F 확정 → 숫자 태그 → 저장 → train-only 증강(학습 3/검증 1)을 임시 프로젝트에서 끝까지 실행해 PASS 확인. pip check/compileall 성공.
