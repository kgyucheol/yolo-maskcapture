# SAM 클릭 라벨링 구현

사용자 요청: SAM2 경량 모델로 포인트 기반 객체 마스크를 만들고 영역 추가·제외, 기존 태그 지정과 왼손 단축키를 이어 사용한다. 단축키 UI도 기능별로 구분한다. 사용자의 구현 요청에 따라 현재 작업 공간에서 진행한다. Git 저장소가 없으므로 커밋/worktree 단계는 적용하지 않는다.

## 설계

- 기존 Ultralytics의 SAM 2.1 Tiny(`models/sam2.1_t.pt`), GPU 자동 선택, 1024 입력. 새 패키지는 필요 없다. 최초 모델 다운로드 및 특징 계산은 전용 스레드에서 수행한다.
- T AI 클릭: 좌클릭 포함/우클릭 또는 Shift+좌클릭 제외. 같은 객체의 모든 포인트를 하나의 prompt로 전달한다. 이미지는 한 번 인코딩하고 재사용한다.
- 초안 마스크와 포인트를 표시한다. F 확정 → 숫자 태그. C 취소, Z/Shift+Z 포인트 취소/재실행. 확정은 기존 document undo 1단계로 들어간다.
- 확정 후 R 브러시/Shift+R 지우개로 직접 수정한다. 다른 도구 전환·이미지 이동은 미완성 초안을 정리할 때까지 차단한다.
- 요청마다 revision을 부여한다. 취소/다음 클릭/이미지 변경 후 도착한 옛 결과는 무시한다. 작업자는 단일 GPU 소유자이며 대기 요청을 최신 1개로 합친다. 오류 후 재시도가 가능하고 종료 시 스레드 정리를 기다린다.
- 도구 버튼 키캡, 선택 강조, AI 모델 상태/불러오기/메모리 해제, 용도별 단축키 안내를 제공한다.

## 작업 및 검증

1. 캔버스: 포인트→미리보기→확정→태그, +/− 보정, 마지막 결과만 확정, 취소·이미지 변경, undo/redo, 브러시/지우개 연계 테스트를 먼저 실패시킨 뒤 구현한다.
2. SAM 어댑터/스레드/라벨링 화면: 이미지 특징 캐시, 포인트 묶음, 원본 크기 마스크, 최신 작업 병합, 오류 복구, 종료 생명주기와 단축키 UI를 연결한다. 비싼 모델 추론만 대체한 자동 테스트와 실제 GPU 추론을 각각 검증한다.
3. 전체 pytest, 실제 SAM2 Tiny GPU 양/음 포인트, 화면 캡처 및 별도 코드 검토. README/도움말 갱신.

## 검토 초점

- 이전 이미지/취소한 초안/빠른 연속 클릭의 결과가 새 객체를 변경하지 않는다.
- 오류/빈 마스크/계산 중 F는 이전 마스크를 확정하지 않는다.
- 포인트는 원본 좌표이고 음 포인트가 별도 객체로 분리되지 않는다.
- 종료 중 실행 스레드를 파괴하지 않으며 수동 라벨링은 모델 없이 동작한다.

## 진행 기록

- 현재 구성 및 설치된 Ultralytics 8.4.60의 SAM2Predictor API 확인. CUDA 사용 가능.
- 캔버스/어댑터/작업자/화면 통합 완료. 실제 GPU에서 848×480 양·음 포인트 마스크 확인. 최초 이미지 499ms, 캐시 보정 7.9ms(예제 1회 측정).
- 전체 테스트 79개 통과(증강 구현 전). 별도 검토의 포커스 상실·메모리 해제 시 수동 초안 소실을 회귀 테스트로 RED→GREEN 수정. 모델 준비 재시도 및 버튼 잘림도 회귀 테스트로 검증.
