# 라벨링·증강 조작 개선

사용자가 요청한 변경을 기존 흐름에 통합한다.

- SAM 경계 슬라이더 -5.0~5.0, 0.1 간격, 기본값 0.0. 음수 확장/양수 축소. F 전 초안에만 적용하고 변경 즉시 이전 revision을 무효화한다. 이미지 특징 재사용, 작업자 단일 큐와 포인트 보존.
- 증강 기법별 체크박스와 강도, single/random/all 적용 방식. UI 기본 random, 최대 3개. 이미지당 적용 기법 수를 1~최대로 무작위 선택하고 중복 없이 고른다. 원본·증강 마스크 비교와 실제 적용 기법 이름을 표시한다. 생성 보고서에도 이미지별 기법/변환 기록.
- 태그 배지는 바운딩 박스 코너 대신 보이는 마스크 영역의 거리 변환 최댓값을 기준으로 배치. 이미지/화면에 맞춰 제한하고 너무 긴 글자는 생략. 마스크가 화면 밖이면 태그도 표시하지 않는다.
- 자동 태그 전파는 사용자에게 연속 장면인지 독립 장면인지 질문한 상태. 설치된 SAM2DynamicInteractivePredictor의 이미지 간 메모리 기능은 확인했다. 이번 명시적 UI 변경과 별도로 가능 범위를 설명하며, 일반적인 클래스 학습과 물체 추적을 구분한다.

## 검증

- 경계 변경의 픽셀 포함 관계, 미확정 이전 결과 차단, 확정 마스크 보존, 모델 미사용 시 슬라이더 GPU 로드 없음.
- single 정확히 1개, random 상한 준수·개수 다양성, all 전부 적용, 선택하지 않은 기법 제외, 재현 가능한 train-only 데이터셋.
- 오목한 마스크 내부에 태그 표시, 이미지 가장자리 클리핑, 확대/이동 시 화면 밖 마스크 처리.
- 전체 pytest, 실제 SAM2 GPU 경계 비교, UI 캡처, 독립 코드 검토.

Git 저장소가 없어 커밋/worktree 단계는 적용하지 않는다. 기존 사용자 데이터는 검증에서 변경하지 않는다.

## 완료 기록

- 경계/증강 조합/태그 위치 회귀 테스트 RED→GREEN, 전체 테스트 100개 통과. 실제 추론이 진행 중일 때 슬라이더를 변경하는 경우도 검사.
- 실제 SAM2 CUDA에서 임계값 -1/0/1의 마스크 픽셀 124487/118884/113198 및 포함 관계 PASS 확인.
- 1440×940 화면 캡처, compileall 성공. 별도 검토에서 Critical/Important 없음.
- 가장자리 작은 객체는 글자 가시성을 위해 배지 중심이 마스크 밖으로 이동할 수 있으나 배지는 객체와 겹치거나 가까이 유지한다. README에 동작 명시.
- 실행 중인 사용자의 편집 프로세스는 유지했다. 변경 적용에는 저장 후 앱 재시작이 필요하다.
