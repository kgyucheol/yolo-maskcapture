# 증강 선택·비율·배수 작업 흐름 개선

요구: 활성화 클릭 문제, x2/x3/x4 생성 배수, 종류별 체크와 미리보기, 무작위 조합 비율 조절, seed 설명. Roboflow의 기법 선택→강도 설정→배수로 새 버전 생성 흐름을 참고한다.

실제 QTest 마우스 클릭 조사: 현재 Qt group 제목의 체크박스/label 클릭은 정상 토글된다. UI는 작은 checkable group 제목에 의존하여 활성화 위치가 불명확하다. 독립적인 큰 QCheckBox + 활성/비활성 상태 안내로 교체하고 실제 마우스 클릭 회귀 검증을 추가한다.

설계:
- 원본 포함 학습 x2/x3/x4/... 배수. 내부 생성 수 = 배수-1. 검증은 원본 유지.
- 기하 / 색상·조명 / 노이즈·화질 탭. 기법별 체크·강도·선택 비중. 비중은 정규화된 상대값이며 정확한 적용 확률이라고 표시하지 않는다.
- 단일/복합 증강본의 비율을 지정. random 모드에서 전체 생성 장수 기준 반올림한 단일 장수를 고정하고 나머지는 2~최대 N개 조합. 가능한 기법이 1개뿐이면 전부 단일.
- 원본 분할과 생성 recipe 계획을 공용 함수로 만들어 미리보기와 생성에 재사용. 이미지별 recipe/seed와 실제 단일·복합 장수를 report에 기록.
- 미리보기는 실제 학습 원본의 생성 예정 샘플을 순회한다. 원본+증강 비교, 마스크 표시 on/off, 실제 기법 이름·단일/복합·예정 장수 표시. 설정 변경은 미리보기에 즉시 반영하고 명시적 생성 버튼으로 적용.
- seed의 의미를 tooltip/도움말로 설명. 기존 원본·주석·데이터셋 비파괴 보존.

검증: 실제 클릭, x4→3장 추가, 고정 단일/복합 quota, 상대 비중, 비활성 기법 제외, 검증 누수 없음, 미리보기=생성 픽셀 비교, 전체 pytest, UI 캡처, 독립 코드 검토.

이 작업 공간은 Git 저장소가 아니므로 커밋/worktree 단계를 생략한다.

## 검증 결과

- 실제 enable 행 중앙 클릭으로 ON/OFF, ×4→원본당 추가3장 확인. 기존 그룹 제목의 작은 hit 영역 대신 독립 체크 행 전체를 클릭 가능하게 함.
- 고정 단일/복합 quota, 상대 선택비중, 한 기법 fallback, 미리보기=저장 이미지 픽셀, train-only 분할 검증.
- 전체 pytest 105 passed. compileall 성공. 1440×940 UI 캡처 docs/ui-augmentation-preview.png 확인.
- 독립 검토 Critical/Important 없음. 별도 실행 service/workflow 20개 통과 및 임베디드 패널 배치 확인.
- Roboflow 공식 segmentation augmentation 안내 참조. 외부 업로드/프로젝트 생성 없이 로컬 앱 안에서 구현.
